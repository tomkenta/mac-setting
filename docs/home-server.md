# Mac mini ホームサーバー設定

家庭内LANでMac miniをヘッドレス運用するための手順。
インターネットへSSHや画面共有のポートを直接公開する構成は対象外とする。

## 1. 自動設定

Mac miniでこのリポジトリを取得し、次を実行する。

```sh
cd mac-setting
./scripts/setup-home-server.sh
```

スクリプトは次を設定する。

- SSH（リモートログイン）を有効化
- SSH接続を実行ユーザに許可（既存の許可ユーザは保持）
- 本体の自動スリープを無効化
- Wake on LANを有効化
- 停電後の自動起動を有効化
- macOSのアプリケーションファイアウォールを有効化
- 署名済みソフトウェアの受信接続を自動許可
- ステルスモードを有効化

何度実行しても同じ設定になる。

## 2. 画面共有

画面共有はmacOSの権限管理と連動するため、GUIで設定する。

1. `システム設定 > 一般 > 共有`を開く
2. `画面共有`をオンにする
3. アクセスを許可するユーザを管理用アカウントだけに限定する
4. `リモートマネージメント`はオフのままにする

別のMacで「画面共有」アプリを開き、`Mac-mini.local`またはIPアドレスへ接続する。

## 3. ネットワーク

- 可能ならWi-FiではなくEthernetを使う
- ルーターのDHCP予約でMac miniのIPアドレスを固定する
- ルーターでTCP 22番や5900番をインターネットへポート開放しない
- 外出先から接続する場合はVPNを使用する

同じLANの別のMacからSSHを確認する。

```sh
ssh -l USER_NAME Mac-mini.local
```

ホスト名はMac miniの`システム設定 > 一般 > 共有 > ローカルホスト名`で確認する。

## 4. 更新とバックアップ

- `システム設定 > 一般 > ソフトウェアアップデート`でセキュリティ対応とシステムファイルの自動更新を有効にする
- 大型macOSアップグレードは、利用中のサーバソフトウェアとの互換性を確認してから適用する
- 重要なデータをMac mini本体だけに置かず、外付けディスクまたは別の保存先へバックアップする
- サーバアプリが再起動後に自動起動することを確認する

## 5. FileVault

FileVaultは盗難時のデータを保護する一方、再起動後にディスクを解除するまでSSHや画面共有を利用できない場合がある。無人での停電復旧と保存データの機密性を比較して、有効化を決める。

## 6. ヘッドレス移行前の確認

- SSHでログインできる
- 画面共有でログインできる
- 再起動後にSSHとサーバアプリが復帰する
- ファイアウォール有効時も必要なサービスへ接続できる
- バックアップから必要なデータを復元できる

すべて確認してから、ディスプレイ、キーボード、マウスを取り外す。
